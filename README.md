# TRO Toolbox

TRO Toolbox Plus adalah aplikasi web sederhana untuk membantu mahasiswa Teknologi Rekayasa Otomasi (TRO) dan bidang teknik terkait melakukan perhitungan teknik dasar.

## Fitur

- Kalkulator Hukum Ohm
- Kalkulator resistor seri dan paralel
- Kalkulator kode warna resistor 4 dan 5 gelang
- Kalkulator persentase error
- Konverter satuan
- Pustaka rumus elektronika
- Informasi tokoh ilmuwan
- Riwayat perhitungan di browser

## Teknologi

- HTML5
- CSS3
- JavaScript
- Git dan GitHub

## Cara Menjalankan

1. Unduh atau clone repository ini.
2. Buka folder proyek.
3. Buka file `index.html` menggunakan browser.

Aplikasi ini merupakan web statis dan tidak memerlukan backend untuk fitur dasarnya.

## Struktur Proyek

- `index.html` — struktur halaman
- `style.css` — desain dan tata letak
- `script.js` — logika dan fitur interaktif
- `README.md` — dokumentasi proyek

## Sasaran Pengguna

Mahasiswa Teknologi Rekayasa Otomasi, pelajar bidang teknik, dan pemula yang ingin mempelajari elektronika dasar.

## Rencana Pengembangan

- Menambahkan kalkulator teknik lainnya.
- Memperluas pustaka rumus.
- Menyempurnakan tampilan dan panduan penggunaan.
